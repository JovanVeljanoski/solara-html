solara-html

Single-file HTML components for Solara.

Early alpha. This project is experimental and is likely to change, or break, with little or no notice. Do not depend on it for anything you cannot rewrite.

Install Motivation Quick start API Examples Security Limits GitHub

Install

pip install git+https://github.com/JovanVeljanoski/solara-html.git

Not on PyPI. Requires Python 3.12 or later, Solara 1.64.0 or later, and a browser from 2022 or later.

Motivation

  • A component is one .html file: a template, CSS and JavaScript.
  • The template is Vue 3 syntax (Vue 3.5.43, vendored). There is no build step.
  • It runs on stock Solara through ipyreact. Nothing in Solara is patched.
  • Python props are assigned in the template. Python events are called as methods, as with Solara widgets.
  • CSS is scoped to the component by a shadow root.
  • An error in one component's template or script shows in that component. The other components keep working.
  • In development mode, a change to the HTML file reloads the app.

The package started as widgetti/solara#1233 by Maarten A. Breddels.

Quick start

Two files in one folder.

hello.html

<template>
  <label>Name <input v-model="name" /></label>
  <p>Hello, {{ name }}!</p>
  <button :disabled="name === 'World'" @click="reset()">Reset</button>
</template>

app.py

import solara

import solara_html


@solara_html.component_html("hello.html")
def Hello(name="World", on_name=None, event_reset=None):
    pass


name = solara.reactive("World")


@solara.component
def Page():
    Hello(name=name.value, on_name=name.set, event_reset=lambda _data: name.set("World"))
    solara.Text(f"Python sees: {name.value}")
solara run app.py

Typing in the input changes the greeting and calls on_name. The button calls event_reset in Python.

API

solara_html.component_html(path)

A decorator. path is the HTML file, relative to the file of the decorated function. The function signature is the contract. The function body is not used.

A change to the HTML file, to a file it imports, or to a CSS file it imports reloads the app in development mode.

Arguments

In PythonIn the template
name="World"A variable name. Writing it in the browser updates Python. Syncs both ways.
on_name=callbackCalled with the new value when the browser changes name. Applies only when name is an argument too.
event_reset=callbackA method reset(data). It calls callback(data) in Python. data must be JSON. The callback gets None when there is no data.
children=[]The Solara widgets shown at the template's <slot></slot>. Only the default slot exists.

Props are assigned (name = "x", v-model="name"). Events are called (@click="reset()"). Python never receives $emit.

The decorator raises ValueError for:

  • an argument named like an ipyreact.Widget attribute, for example keys, comm, open, close, layout, model_id, tooltip, tabbable, events, props, or an argument that starts with _;
  • two arguments that give the same React prop, such as a prop and an event with the same name, or x and setX;
  • a template that uses v-html, :innerHTML, :outerHTML;
  • a missing <template>, a missing imported file, an import cycle, or a CSS @import that is not a relative file.

Props and event data are JSON: str, int, float, bool, None, list, dict. A whole number that the browser writes to a float prop reaches Python as an int.

The file

Part
<template>Required. Vue 3 template syntax: {{ }}, v-model, v-if, v-for, v-show, :attr, @event, refs.
<style>Optional. Applied in a shadow root, so it does not leak in or out. @import "./file.css"; is inlined and watched.
<script type="module">Optional. Export a Vue options object named component. Props and events are this.<name>. Relative import statements of other .js files work. import ... from "react" works as in any ipyreact module.

Use the options API: data, computed, watch, methods, lifecycle hooks, components. A computed or methods entry must not have the name of a prop or event.

v-safe-html

v-safe-html="text" shows markup from Python or users. It parses without running anything, keeps a short list of tags and attributes, and drops scripts, frames, forms and event handlers.

Errors

  • A mistake in the template or a method shows as a red message in the component.
  • A JavaScript error in the script or a file it imports shows in that component as file: error.
  • In development mode (solara run without --production), the browser console also warns about template mistakes, such as a name that does not exist.

Examples

A list the browser edits

A list prop changed by assignment or in place (item.done). Python gets both.

tasks.html

<template>
  <form @submit.prevent="add">
    <input v-model="draft" placeholder="New task" />
    <button>Add</button>
  </form>
  <ul>
    <li v-for="item in items">
      <label>
        <input type="checkbox" v-model="item.done" />
        {{ item.text }}
      </label>
    </li>
  </ul>
</template>

<script type="module">
  export const component = {
    data() {
      return { draft: "" };
    },
    methods: {
      add() {
        if (!this.draft) return;
        this.items = [...this.items, { text: this.draft, done: false }];
        this.draft = "";
      },
    },
  };
</script>

app.py

import solara

import solara_html


@solara_html.component_html("tasks.html")
def Tasks(items: list = [], on_items=None):
    pass


items = solara.reactive([])


@solara.component
def Page():
    Tasks(items=items.value, on_items=items.set)
    solara.Text(f"Python sees: {items.value}")

Style, slot and an event with data

The children of the Python call appear at <slot>. The event passes a value to Python.

card.html

<template>
  <div class="card">
    <h2>{{ title }}</h2>
    <slot></slot>
    <button @click="choose(title)">Choose</button>
  </div>
</template>

<style>
  .card { border: 1px solid #999; border-radius: 8px; padding: 1rem; }
  h2 { margin-top: 0; }
</style>

app.py

import solara

import solara_html


@solara_html.component_html("card.html")
def Card(title="", event_choose=None, children=None):
    pass


chosen = solara.reactive("")


@solara.component
def Page():
    with Card(title="Plan A", event_choose=chosen.set):
        solara.Text("These children are Solara widgets.")
    solara.Text(f"Chosen: {chosen.value}")

Security

  • Treat the template as code you wrote. Treat values from Python or users as untrusted.
  • v-html and :innerHTML are refused. Use v-safe-html.
  • A guard removes every attribute whose name starts with on, srcdoc, and a URL in href, src, action, formaction, poster, data, xlink:href unless it is relative or uses http:, https:, mailto:, tel:.
  • Never bind untrusted data to <component :is>. A tag name such as script runs. This is not detected.
  • The template is compiled in the browser, so the page's Content-Security-Policy must allow unsafe-eval.

Limits

  • Early alpha. The API can change at any time.
  • Built for the Solara server. Jupyter is not a goal.
  • Only the default slot.
  • Python cannot call a method in the browser. Send a value the browser reacts to, such as a counter prop with a watch.
  • No to_json / from_json, no binary buffers.
  • Vuetify and Solara classes do not apply inside a component.
  • Relative imports in scripts are rewritten with regular expressions. Dynamic import() does not work.
